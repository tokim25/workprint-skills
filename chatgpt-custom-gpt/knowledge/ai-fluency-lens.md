# AI Fluency Lens

Workprint can use the AI Fluency 4D lens to describe how a person worked with
AI when the evidence supports it.

Credit the lens as part of the AI Fluency framework from Anthropic Academy and
its framework authors when naming it in a formal report. Do not imply that
Workprint owns the framework.

## The Four Ds

- Delegation: evidence that the user assigned work, set constraints, chose what
  AI should handle, or decided what should remain human-led.
- Description: evidence that the user supplied goals, context, examples,
  acceptance criteria, or desired output shape.
- Discernment: evidence that the user reviewed, questioned, corrected,
  accepted, rejected, compared, or refined AI output.
- Diligence: evidence that the user tested, checked, verified, preserved
  boundaries, handled risk, or documented what remains unknown.

## How To Use This Lens

Use the lens to help the user understand their collaboration pattern. Do not
turn it into a grade, personality judgment, or productivity score.

Good:

> The captured turns show discernment: the user rejected a broad first answer
> and asked for a narrower implementation path. Evidence: CHAT-004.

Good:

> The summary evidence suggests delegation and description, but the full chat
> is not present, so Workprint cannot verify every underlying turn. Evidence:
> SUMMARY-002.

Bad:

> The user scored 82% on delegation.

Bad:

> The user was highly diligent because many commits exist.

## Boundaries

- Do not infer a 4D pattern from file counts, line counts, or message volume.
- Do not assign contribution percentages.
- Do not claim the user demonstrated a skill unless specific evidence supports
  the narrow behavior.
- Prefer "appears" when the role is supported but not directly stated.
- Prefer "unknown" when the evidence does not show the behavior.
